# Fuentes primarias

Consultadas el 17 de octubre de 2026. Las páginas describen esta configuración personal; no afirman que Google haya verificado la aplicación.

- GitHub Pages: disponibilidad en repositorios públicos con GitHub Free, formato de URL de sitios de proyecto y registro de IP por seguridad. https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- Google: homepage pública y relevante, política de privacidad en el mismo dominio, divulgación del acceso/uso/almacenamiento/compartición y regla del dominio privado superior para Authorized domains. https://developers.google.com/identity/protocols/oauth2/production-readiness/brand-verification
- rclone: configuración de cliente propio de Google Drive y uso de GitHub Pages para homepage y privacidad. https://rclone.org/drive/#making-your-own-client-id
- Public Suffix List: `github.io` figura como sufijo público; el dominio privado superior de este sitio es `varboledaec.github.io`. https://publicsuffix.org/list/public_suffix_list.dat
- Google Account: gestión y revocación de conexiones con aplicaciones. https://myaccount.google.com/connections
- Google Drive API: descripción del permiso de acceso completo a archivos. https://developers.google.com/workspace/drive/api/guides/api-specific-auth

El alcance y el flujo descritos en la política corresponden a la configuración informada por su titular. No se publican correos privados, identificadores de cliente OAuth, secretos, tokens, identificadores de carpetas ni archivos de respaldo.
