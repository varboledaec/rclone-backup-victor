# rclone-backup-victor

Web informativa en español para el respaldo personal de Victor Arboleda con rclone y Google Drive.

- Inicio: https://varboledaec.github.io/rclone-backup-victor/
- Privacidad: https://varboledaec.github.io/rclone-backup-victor/privacy.html
- Contacto: https://github.com/varboledaec o las consultas públicas de este repositorio.

## Publicación

GitHub Pages sirve la carpeta `docs/` de la rama `main`. El sitio usa HTML y CSS estáticos, sin JavaScript, formularios, analítica ni dependencias externas de diseño.

## Alcance

Este repositorio contiene únicamente las páginas informativas y sus fuentes de referencia. No contiene respaldos ni configuraciones o credenciales de rclone. La web no autoriza ni ejecuta operaciones en Google Drive.

El permiso `https://www.googleapis.com/auth/drive` permite acceso amplio a la cuenta autorizada; no constituye una restricción a una carpeta. El uso previsto de la configuración es el respaldo personal del titular. La autorización y las pruebas de rclone se realizan fuera de esta web.

## Dominio para la configuración OAuth

El dominio de ambas páginas es `varboledaec.github.io`. La Public Suffix List incluye `github.io`; por tanto, el dominio privado superior de estas URL es `varboledaec.github.io`. Es el valor que corresponde a Authorized domains, sin protocolo ni ruta. La aceptación o verificación en Google Cloud es un paso separado.
